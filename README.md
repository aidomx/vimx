## Quick Start

```bash
curl -fsSL https://raw.githubusercontent.com/aidomx/vimx/main/install.sh | bash
```

## Features

- **Modular Structure** — organized config for languages and frameworks
- **Full LSP Support** — autocompletion, go-to-definition, diagnostics via coc.nvim
- **Mobile Optimized** — touch-friendly key mappings and Termux-native experience
- **vimx CLI** — manage plugins, languages, themes, backups from one tool
- **Full-Stack Ready** — React, Next.js, Laravel, C/C++, Python, Go, Bash

## vimx Commands

```bash
vimx install        # First-time installation
vimx update         # Update all plugins
vimx add <plugin>   # Add new plugin
vimx disable <name> # Disable plugin
vimx doctor         # Health check
vimx help           # Show all commands
```
